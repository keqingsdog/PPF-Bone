# 骨骼姿态缓存另存

另存前迁移骨骼姿态索引和帧，复制失败会保留旧引用并在求解器面板提示保留旧缓存。既有残缺或不兼容目标不会覆盖，需换新文件名。Save Copy 保留当前会话引用；实际保存失败恢复旧引用和警告。普通同路径保存不重新读取全部缓存。

此功能仅迁移骨骼姿态缓存，不迁移 PC2、其他缓存或远端项目/续算状态；不能据此认定新工程可脱离原项目独立续算。并发写入和崩溃后的完整事务恢复不在保证范围。

Windows Blender 定向验证可运行 `python tools/saveas_test/run.py --blender <blender.exe> --work-dir <新的空目录>`。仅使用合成骨骼缓存，不调用求解器。
