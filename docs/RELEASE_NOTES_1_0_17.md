# 插件 1.0.17 修复说明

本次更新插件，沿用此前正式引擎。引擎源码以基于官方 2026-09-27 的上一正式完整源码为基础，保留 CPU、CUDA、Metal、ROCm 等原有构建路线；没有将新硬球关节实验加入正式引擎。

## 材质与软关节

- 简单骨骼物理界面直接显示柔体代理的材质模型、硬度（MPa）、泊松比和变形阻尼。
- 读取现有独占代理组的实际材质，正确处理按密度归一化的旧组；修改一个字段不覆盖其他字段。
- 保留多选即时编辑和材质预设，失败时恢复相关作者属性与组材质，包括原先未显式设置的状态。
- 新建柔体代理默认硬度为 500 MPa，密度为 1 kg/m³；已有工程保留自身实际值，不以新默认值覆盖。
- 简单界面增加连接刚度（N/m），角刚度和角阻尼继续使用原有每度控件，避免重复出现两套入口。启用恢复曲线时，常数入口标明由曲线接管。

旧引擎没有独立的连接平移阻尼接口，因此本次没有增加一个无法传输或不生效的参数。角阻尼和柔体变形阻尼是各自独立的真实参数。

## GPU 代理层

同帧更新 PC2 后，原求值网格可能继续使用旧缓存。本次在实际写入成功后只标记对应网格的数据需要重新求值，复用既有快照刷新路径；没有在每次绘制时扫描或求值整个场景。

验证包含旧正式 CPU 引擎的真实柔体骨代理、跨帧及同帧回传顶点比较，以及正常 GPU 视口显示。测试夹具的较软材质仅用于显现形变，不修改产品默认值。

## 范围和限制

新硬球关节按用户要求暂缓，实验代码和失败证据留存在独立开发树中。既有其他关节模式不因本次暂停被删除。

此前的原生 Undo 崩溃尚未确认完全关闭；多版本注册与依赖测试不等于所有交互路径的稳定性证明。Metal/ROCm 等未在本次机器上实跑的项目应保持未验证标记。

具体运行结果、兼容性范围和剩余问题随交接文档提供，不以编译、注册或截图单独代表所有功能验收。
