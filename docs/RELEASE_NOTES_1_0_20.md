# 1.0.20 修复说明

本候选修正骨骼姿态完成后普通刚体代理及链间弹簧的当帧发布。原注册顺序可能让显示回调早于骨骼姿态完成，造成当帧缺失；现已做同步发布修复。此前动态 PC2／形态键的专项证据保留各自范围。作者跟随误将播放视为编辑、接近90°姿态的假剪切拒绝及重开首帧观察值缺失也已定向修复。新建 Key 的完整烘焙使用绝对形态键及单条 eval_time 曲线，已有作者形态键保留原路径，旧数据不自动迁移。

实际候选 ZIP 在私有 Blender 5.1 进程中安装，插件及 cbor2 从私有扩展加载；自然注册处理器下三帧共24次绘制，覆盖2个普通刚体、409条链间连接、142个 PC2，PC2坐标／世界矩阵对照误差为0，observer 和 native consumer 各执行3次，进程退出0。首轮探针误将闭包变量当作普通局部变量，显示测试前失败；重试只修探针并在新私有目录运行，同一 ZIP 未修改。额外变量镜像断言不作为产品验收。证据见 `native-publication-fix/candidate20-retry-installed`。

144 PC2 与408条链间连接的完整显示样例，3秒从58帧提高至67帧，帧间隔中位51.65→44.34ms，P95 57.55→48.86ms，最大59.97→52.48ms。用户已接受当前速度；此为固定样例，不承诺其他场景达到60 FPS。此前 GPU 开启测试没有完整绘制刚体和弹簧，不能作为完整显示性能基准。异步播放实验未合入生产。

本交付内容为1.0.20，实际部署和云盘同名替换结果以本次交付回执为准。本轮保留原有CPU、CUDA、Metal、ROCm源码与构建路线；各平台只按实际测试范围声明。硬球关节和原生 Undo 崩溃按用户决定暂缓；CUSTOM回滚交 Linux 检查，故障注入验收未确认；按权重生成代理仅待办。不能把有限场景通过当作所有功能或平台均通过。

早期CLI测试写过用户偏好，缺少事前副本，影响范围未知；早期GUI测试未隔离TEMP/TMP写入系统临时quit.blend，未知是否覆盖原退出恢复。后续测试隔离配置和临时目录，事故二进制与用户偏好不进入分享包。
