# 2026-10-28：跨链弹簧与单帧恢复

## 本轮功能

- 跨链连接分别设置拉伸／压缩开关与刚度（N/m），阻尼使用共享数值（N·s/m）。关闭某一方向会同时关闭该方向的弹性及阻尼。旧请求保留旧行为，包括零刚度、非零阻尼的纯阻尼连接。
- 跨链连接可单独排除骨对碰撞；它与同链邻骨排除合并去重，并继续服从原生组过滤。排除不创建额外碰撞组，显式排除不能被其他组设置重新打开。
- 跨链列表将编辑模式提示与真正失效端点分开；刚度／阻尼数值使用明确的单位。创建、批量设置、预设、MCP 和专用骨架复制均保留新增参数。
- 新的网格／骨骼 Single 保存可恢复状态；可以恢复单帧前的模拟并继续完整 Bake，也可保留单帧结果后结束恢复。Curve 和混合 Curve 保留原 Single 流程，界面明确其不可用新入口恢复。

## 源码结构与兼容

正式源码以当前发布源码根为准；本地开发树为 `remaining-issues-20261028/formal-source-20261029`。`plugin-external-handoff-20261024/portable-source02` 是暂缓封存的硬关节实验树，不作为正式交付源码。本机完整运行包为 `<运行包根目录>`。本分支保留 2026-09-27 官方工程结构与 CPU、CUDA、Metal、ROCm 构建路线；本轮只在 Windows CPU/CUDA 进行原生验证。

方向控制复用 kind 5 距离弹簧和 SIGNED 曲线；现有 48 字节绑定的保留字段承载显式方向语义。语义加入原有 ABI 输入并由现有生成器输出 Rust/C++ 身份文件，不手改摘要常量。旧 mask 0 维持原模型。

跨链碰撞使用独立封存 sidecar，经过场景输入、真实顶点归属及精确 CSR 安装验证。它不伪造父子关节。孤立 sidecar、缺失能力或旧程序必须明确拒绝，不能忽略请求。

源码分享 ZIP 不含开发机 `LOCAL_SOURCE_BUILD.json`；运行包使用 v2 相对路径配置。编译使用 `BUILDING_BONES.md` 中的标准入口，不依赖本轮私有夹具或旧对象文件。CPU/CUDA 产物按后端隔离，解释器、绑定、程序和 GPU 库须配套更新。

## 使用与交接
