# 界面显示修正（2026-10-27）

用户实际反馈：双栏背景过于透明、原有面板不易辨认、找不到骨骼物理，且仍出现独立碰撞组模块。

本次只改五个界面文件，保持已发布的插件core、前端和求解器不变；并行进行的Linux累计返包不混入本次紧急界面安装包。

- 经典模式保留原有原生面板；布局选择固定在顶部。双栏使用有背景的模块块和标题，窄侧栏仍单列回退。
- 骨骼物理入口在未选骨架时也显示选择提示，在经典模式下紧随动力学组，不要求用户先猜出隐藏入口的条件。
- 每个动力学组的碰撞层折叠区真正位于该组框内部，固定操作该组全部参与成员。
- 隐藏公开的独立“物体碰撞组”面板，并移除双栏中的同名单独模块。后台对象／骨骼16层字段、MCP及既有数据保留；骨骼参数里的单骨设置仍属原功能，相邻骨排除的语义不变。

真实中文Blender5.1.2测试使用正式运行包ZIP，仅替换上述五文件：21项检查通过，进程自然退出0。覆盖约320／700逻辑像素、普通Cube场景骨入口、组内表、经典顺序与统一侧栏分类。此次没有运行或宣称新的物理解算验收。

当前用户窗口已仅切回经典界面，未改场景或物理。磁盘更新后的插件需正常重启Blender才能载入；不热重载用户实例。组内UI分区的折叠状态只在本进程保留，不影响物理配置。
