# Windows完整运行包使用

本包同时保留CPU和CUDA运行产物，文件夹可以整体搬移。源码基线仍是官方2026-09-27，不是最新main升级。

1. 将运行包内`PPF骨骼插件_源码运行包v2_20261024.zip`通过Blender“从磁盘安装”安装，然后重启Blender。本轮已安装插件只补交互故障，不会自动更改用户连接路径；使用新运行包应选它的配套v2插件。
2. 在插件的Windows原生连接中，“求解器路径”选择**整个运行包根文件夹**，不要选`python.exe`或单独EXE。
3. 普通场景可按需选择CPU或GPU；本轮骨链实际求解使用CUDA。CPU普通场景已实跑，CPU新增骨骼仅部分能力准入，不等于CPU骨链已验收；缺少的新增功能会按请求报错，不会偷偷改选CUDA。
4. 继续正常连接、传输场景、构建、运行和自动缓存。手动拖帧或播放会把时间轴交给用户，取帧继续；需要追上最新结果时点击“恢复实时跟随”。完成取帧后由用户控制播放，不再自动启动循环。

包内`python/python.exe`是前端Python解释器；两个实际求解器分别位于`target/cpu/release/ppf-contact-solver.exe`和`target/cuda/release/ppf-contact-solver.exe`。日常通过插件使用根目录，不必手工切这些文件。

CUDA库包含上游七个原生目标61/75/86/89/90/100/120，本机实跑仅RTX4070TiSUPER。Linux、Metal、ROCm源码和原构建路线仍保留；Windows包不等于其他平台实测通过。
