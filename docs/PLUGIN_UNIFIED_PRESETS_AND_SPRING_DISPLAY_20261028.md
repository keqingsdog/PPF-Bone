# 2026-10-28 插件：统一预设、复制清理与链间弹簧显示

状态：程序化功能测试通过，最终范围审查 STATUS PASS / FINDINGS NONE。仅发布本报告所述插件补丁，不扩大为全局 GUI 或长期场景验收。

## 操作与语义

“骨骼预设”统一内置骨链和跨工程用户预设，选择来源后使用同一应用范围和应用按钮。应用内容分别勾选关节/恢复、材质、质量/密度、形状、碰撞、显示。内置预设仅提供前三类；没有的类别不显示。用户预设保存、覆盖、刷新、管理入口保留。开关控制本次应用，不会持续接管后续手动编辑。

内置织带的质量方案是密度 200 kg/m³，软体材质方案为 100 MPa；取消质量项保留当前质量输入及有效密度。内置恢复力方案含三轴及连接通道、阻尼和自动软限位，继续按质量与惯量适配，不换刚体/软体类型。用户完整预设的材质项包括物理类型，关节项包括根控制、驱动、限位和恢复曲线；各项边界以提示为准。未选内容必须保留，全不选不写场景。

恢复力读取：固定作者值可以本地读取；自动值需要当前有效构建才可显示实际刚度，缺少时标为“未计算”。铅笔创建固定刚度草稿，点击应用才替换该轴；部分值不可读取时保留当前骨骼未应用草稿，不绕过构建来源校验。

专用复制工具清除新代理继承的管理标记，让既有集合管理移除复制过程中临时创建的场景根链接。删除独立副骨架可沿自然清理删除其代理和材质组，原骨架及用户额外集合链接的保护保留。没有扩大不明历史孤儿的自动删除范围。

GPU代理显示中新增链间弹簧、颜色和线宽。端点按当前骨姿态显示，软体锚点为近似；这是连接示意，不表示实际求解力。关闭代理表面/线框仍可单独显示弹簧线；主开关、仅选中和视层隐藏同样生效。

## 已有范围证据

- 复制：私有 Blender 5.1.2 三个副代理修前可复现根链接/删架残留；修后自然清理、用户集合保护及故障回滚通过。普通复制隔离为直接函数测试，不代表 144 骨复制规模验收。
- 显示：私有 Blender 5.1 GPU 窗口 144 条弹簧、姿态/物体移动、自然刷新、禁用/失效、模式切换、仅选中和关闭资源通过；自然视层 hide/exclude 隐藏 144→0、恢复 0→144，无手动 capture。capture 均值样本约 11.1 ms，不代表整体流畅度验收。
- 恢复力：独立配置中无构建四通道预设、固定草稿编辑与应用、混合读取及未应用草稿保护通过；实际 UILayout 绘制过内置和用户来源，不是截图视觉验收。

- 内置选择应用：私有 Blender 5.1.2 恢复/材质/质量单独应用及全关通过，保留未选作者及实际组参数；该测试用替身指定目标骨，不冒充目标选择界面测试。
- 用户选择应用：私有 Blender 5.1.2 真实 capture、恢复 only、形状 only、刚体/软体双向材质 only、全关和原默认 full 路径通过。材质切换保留同一代理对象/Mesh、坐标、变换和未选质量参数。若旧作者密度与实际组密度已失配，关闭质量时在写入前明确拒绝切类型，不能暗中规范化未选质量。
- 作者保护与回滚：嵌套 drive 遗留动画在选择关节项时拒绝并保留作者状态，未选关节时可应用显示且保留该动画；第二目标提交中注入故障后，前一个已经修改的网格、两目标属性、组、变换、恢复曲线全部回滚。最终定向运行退出 0，见 preset-user-test/final-directed.log。
- 原测试搭建失败保留说明：第一次以 ID.driver_add 建立 gain 动画被当前 RNA 的“不可动画”设置拒绝，尚未进入产品调用，不能称通过。随后仅测试器改用 AnimData.drivers.new 种入遗留 FCurve；Blender 对其有 Invalid driver 警告，但保护门实测通过。没有将字段改为可动画或放松作者保护。

测试入口：worker-test/、spring-test/、restoring-private-test/run.py、preset-mask-test/test_mask.py、preset-user-test/directed.py。没有新增长期 native 或真实 GUI 乱序点击验收。
