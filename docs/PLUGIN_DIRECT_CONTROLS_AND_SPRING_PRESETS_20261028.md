## 用户问题与修改

原摩擦双字段来自同一独占材质的 friction：一个是批量桥，一个是真实可动画 RNA。普通面板现在只有一个批量摩擦值；关键帧通过右侧按钮按需展开真实活动骨骼材质。已有动画或自动关键帧时明确只编辑活动骨骼，不暗中冒充批量。用户预设摩擦随“材质”应用，碰撞类别只处理分组、排除和间距；内置预设没有摩擦数据时保留当前值。

原恢复力铅笔草稿由旧线性参数播种，不能当作各预设实际恢复力。现在选择和作者状态自动刷新，固定值编辑按对应父关节立即提交，不再显示读取/应用按钮。首次“自定刚度”明确输入新刚度与阻尼后确认；其他轴保留。AUTO 与自定义非线性通道不灰显旧数值。根无父关节时禁用这块；混合选择跳过根并报告，非物理父级跟随保持现有规则。旧 Load/Apply API 和 trusted_build 验证保留供兼容调用。

**已知边界：尚未接入构建后实际 AUTO K/C 的自动显示缓存。** AUTO 界面只显示质量适配状态，不提供假定惯量的数值。固定物理值可以直接设定；已缓存模拟的物理参数编辑仍需要先清除旧模拟。

中文生成界面的 LOD 改为“面数”，内部档位与网格生成算法不变。固定 SI 按钮的中文改为“自定刚度”，物理单位保留。

实际用户 5.1.2 场景中，4 条弹簧已进入 GPU 绘制队列；沿线 12 个视点采样都被 Cylinder 遮挡。弹簧现在独立“连接透视”且默认开启，使用像素线宽 shader；不改变代理的透视开关。每条连接可自定义颜色，或继承全局色。选中时橙色外沿仍保留真实颜色内线，不会让选中编辑的颜色失去反馈。颜色样式变化复用代理几何缓存。

## 新链间弹簧操作

“链间弹簧”内包含创建、实际参数、GPU 显示和独立预设。骨骼代理编辑区不再重复放弹簧显示控件。

- 创建参数只供创建新连接使用。已有连接的实际参数实时显示；编辑字段只修改该字段。当前条目勾选时批量修改勾选条目，否则只修改当前条目；混合值有提示。原重复“仅应用拉伸/压缩/阻尼/应用选中”按钮从界面移除，旧 API 保留。
- “仅保存选中骨对碰撞排除”精确使用视图中恰好两根物理骨骼；已有连接只修改这对的排除字段，不改变弹簧参数。没有连接时创建无弹簧力的排除记录。状态区分已记录、未排除以及连接停用不导出；重新传输并构建后才进入新模拟，不把作者状态当成当前求解器已生效。
- 原现场排除未成功的直接原因：旧按钮读取连接列表的勾选项，并写入上方草稿复选框值，不是直接对视图两骨强制排除。只读检查时 4 条记录的 exclude_collision 全为 false，导出骨对为 0；没有替用户猜选区或改原场景。
- 同链及父子骨对可以连接；自连接拒绝，重复创建不覆盖已有参数。双斜向在“平面/筒形”方式中显示；单骨对只有一条边。
- 独立跨工程预设保存拉伸/压缩开关与各自刚度、共享阻尼、碰撞排除和 GPU 颜色，可分别勾选应用。保存来源可选当前连接或手动创建参数。初始距离和骨架身份不跨工程套用，重记参考仍是独立操作。旧整张网络导入/导出入口保留。
- 只改变显示颜色时允许保留模拟缓存，不修改物理来源或初始距离；只要包含物理/排除修改仍走原严格门。旧活动骨架的 UI 指针不能在切换骨架后写回旧对象，身份重建门必须先于端点读取。

## 待办：真实圆锥摆动限位，未实现

当前独立 Y/Z 角界不是圆锥。现有 exact swing-twist chart 可复用，但需要新增 schema/POD/capability 和联合 2×2 摆动算子，贯通 RR/FEM 的能量、梯度、matvec、块预条件与遥测；X 扭转维持独立上下限，圆锥模式不得重复叠加旧 Y/Z 约束。

最小能量为 r=√(sy²+sz²)、E=½k·max(0,r−α)²。外侧 n=s/r，梯度 k(r−α)n，摆动 Hessian 为 k[nnᵀ+(1−α/r)(I−nnᵀ)]，需保留 YZ 交叉项。经 chart Jacobian 的 JᵀHJ 是 PSD/Gauss–Newton 拉回，不能称包含 chart 二阶项的完整 Hessian。边界 C1、非 C2；继承 chart 的有限/奇异域门，不能因 α<π 就认为试探姿态不会遇到 π 奇点。圆锥与椭圆及 AUTO 惯量策略应明确分阶段。

后续验证须包括旧方形区间内但圆锥外的对角点、轴/对角同 r 同能量、独立 twist、边界/零附近/外侧、有限差分和 RR/RF/FF 两后端实际 Build→Run。本轮未修改引擎或宣称此功能已存在。
