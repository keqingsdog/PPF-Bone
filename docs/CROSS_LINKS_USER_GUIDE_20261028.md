# 跨链弹簧操作

本轮新增的双向力与跨链碰撞排除须使用验证后配套发布的插件和求解器。原生构建与运行未结束时，不以界面存在作为功能已经发布的证据。

## 创建连接

1. 为同一骨架中需要的骨骼创建物理代理，确认端点参与物理。
2. 在姿态模式选择这些骨骼，展开“骨骼物理 → 跨链连接”。
3. 选择连接方式后点击“创建跨链连接”。
   - 骨对：选恰好两根物理骨，生成一条弹簧。
   - 平面：选至少两条等长、连续、无分叉骨链。按各链空间中心的主要方向排序，将相邻链的同层骨骼连接。
   - 筒形：选至少三条这样的骨链。按链中心围绕整体中心的角度排序，同层连接并首尾闭环。
4. 可选“双斜向”：在相邻链的每个格子里添加两条 X 形弹簧，抵抗斜向剪切。它会增加连接数。
5. 可选“按质量初始化”：由两端实际有效质量估算刚度和阻尼初值，目标为单对弹簧 2Hz、阻尼比 0.7。它不改变物体质量，也不会持续覆盖手调值。

三种连接方式的名称和用途来自 BoneX；本分支重新实现了配对。所检查 BoneX Python 包按链中心距离为每链选择两个近邻，平面模式再删较远边。PPF 分支采用空间排序，不保证不规则排列时与 BoneX 生成完全相同的骨对。

## 调整受力

- 勾选需要批量修改的连接。
- 拉伸开关与“拉伸刚度 N/m”：控制锚点间距变大时的回复作用。
- 压缩开关与“压缩刚度 N/m”：控制间距变小时的回复作用。
- “共享阻尼 N·s/m”：控制启用方向的相对伸缩振荡。关闭一个方向会同时关闭那个方向的弹性和阻尼作用。
- 单独应用拉伸、压缩或阻尼可保留另一方向的设置；“应用选中”提交整组参数。
- 旧预设迁移为两个方向都启用且刚度相同；新预设保存两方向和碰撞排除设置。

零力参考来自每次模拟的起始姿态。它约束两个锚点间距，不锁定相对朝向，不代替父子关节的弯曲或扭转。双向都关且连接仍启用时，显式碰撞排除仍按设置生效。

## 碰撞与提示

“排除连接骨对碰撞”只排除实际启用连接中的那一对物理体，包括被创建的斜向连接。关闭整条连接后，该连接不再贡献排除对；其他规则贡献的排除不受影响。

原生碰撞组、同链邻骨排除和跨链骨对排除共同生效。碰撞必须先被原生组允许，而且未被任何对象对规则排除。重复对会去重，不额外占用 16 个组。

旧界面在骨骼编辑模式把“请退出编辑模式”误标成整行红色，并不是弹簧过载。新版应将模式提示与真正的失效端点分开。原列表的两列数字是刚度和阻尼，不是距离或测得的力。
