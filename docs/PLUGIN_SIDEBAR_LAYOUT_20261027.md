# 插件布局与组内碰撞层（2026-10-27）

本次只调整插件界面和既有碰撞设置的批量入口，不改变求解器、碰撞公式、骨骼父子关系或用户网格。

## 布局

插件侧栏最上方的“界面布局”可切换“经典／双栏”。首次启用默认经典，保留原有纵向面板。选择双栏后，拉宽侧栏可让连接、求解及场景工具与动力学组、骨骼物理等模块左右并排。侧栏不足约680逻辑像素时，工作台自动单列显示并提示拉宽，不调整用户工作区大小。

双栏内各模块可以独立折叠，跨链弹簧也有入口。布局模式及折叠偏好属于插件偏好，不写入物理配置；切换不重新注册插件，也不重建场景。已有Blender实例需要保存工程并正常重启，才能加载磁盘更新。

## 语言

插件语言独立于Blender本体。偏好选择跟随Blender、中文或English，正常重启后统一生效；不会修改Blender全局语言、界面/提示/数据名称翻译开关，也不热重注作者属性。旧“同步Blender”方案已被用户否定，由此方案取代。

插件专属CONFIG只保存语言选择；详细范围、旧偏好迁移和多版本结果见`PLUGIN_LOCAL_LANGUAGE_20261027.md`。English仍有部分既有中文源词条，未宣称全量英文覆盖；用户命名、路径、专业缩写保留。

## 动力学组的碰撞层

展开动力学组，在该组下面展开“碰撞层”。这里固定作用于该组所有参与解算的成员，不依赖当前选择。普通网格修改物体设置；骨骼代理修改对应骨骼的有效设置。

1. 设置“所属层”，可多选1至16层。
2. 设置“允许碰撞的层”，再启用过滤。
3. 双方都允许对方所属层才产生网格碰撞。关闭相邻骨骼碰撞是在此结果上追加排除，不会把已经禁止的碰撞重新打开，也不占用额外层。
4. 组成员原值不同时，混合位显示横线。点击只统一当前一位，其余位保持；开关过滤也不重置层选择。
5. 修改后重新传输和构建，已运行的输出不会自动重算。

动力学组继续管理材料和参与成员，并非新增一套后端碰撞组。现有对象/骨骼设置与此批量入口共用同一套16位数据；同一对象出现在多个动力学组时，显示的也是同一份实际设置。组外及被排除成员不受当前组的批量修改影响。

解析墙和解析球仍使用原有约束路径，不因网格碰撞层而关闭。原生允许相交及时间窗仍是独立碰撞例外。此界面不扩大后端能力声明。
