# 1.0.27：候选 1017 整合与已知问题修复

本版基于正式 1.0.26 整合经复核的 1017 插件改动，并补修 Windows、Pin 操作、预设保存、动画恢复及缓存重新接入中的具体问题。原生求解器和各后端构建路线沿用已有版本。

## 行为变化

- Scene、材质、Pin 预设按名称保持身份；插入新条目不改变旧选择。组槽位复用清除旧绑定，组迁移和冷重开保留名称及手工参数。
- Scene、材质、Pin、Connection 的普通 Save 写当前绑定；显式文件路径和文件选择器确认遵从所选目标，更新绑定。无效路径不回落写旧文件。
- Pin Make/Delete 限定当前 Action slot 和目标顶点，保留其他 Pin 与通道。共享 Action/Mesh 按当前对象按需复制；重叠冲突明确拒绝。异常时回滚原数据、模式和标记；不能完整回滚时明确报错并保留资源。
- 恢复记录保留并核对参与对象的原 Action 与普通 driver/NLA 结构。源关键帧、驱动或 NLA 关系被改动时拒绝覆盖并保留记录；纯 Action Slot/NLA 选择变化不误报动画漂移。
- 缺少充分历史证明的旧恢复记录不自动补签名。已验证的旧记录可通过保留资源的 Keep 路径退出；旧缓存、源动画和必要备份保留。
- 旧 Curve Keep 后保存重开保持脱离缓存。再次向相同路径提交新输出时自动保留旧文件和 locator，成功接入新结果；本地失败补偿恢复旧文件、标记和读取状态。
- Windows 缓存检查分别比较同一接口前后状态，避免 fstat 与路径 stat 的时间字段差异误拒静止文件；实际写入与文件替换仍被检测。
- 上传准备提前执行已有的显式 scale 曲线/driver 拒绝条件，覆盖参数上传和实际进入作者同步的数据上传，避免确定失败先触发切帧；原本允许的跳过同步分支和后续动态检查保留。

## 验证范围

开发验证使用 Windows Blender 5.1.2 私有程序化场景及实际生产入口，包括完整与单帧恢复、编辑保护、预设保存和公共迁移、Pin 多组/共享数据与故障回滚、旧记录保存重开、源动画漂移、缓存迁移及本地 Curve 输出提交。

骨骼结果使用合法合成 pose/receipt，Curve 使用合法合成 PC2。本地 resume 测试执行真实准备和提交方法，session/fence 为合成状态，不等于本轮运行完整原生服务续算。META 子树使用受控结构测试；普通 CLIP/driver 和保存重开使用真实 Blender 数据。

本轮代码已高级审查通过。实际插件 ZIP 安装和部署结果见随最终交付提供的安装证据与本轮说明；不能将源码测试直接称作安装测试。

## 保留的边界

旧记录缺少证明、共享身份歧义或来源已编辑时，Restore 仍可能拒绝；Keep 也需满足实际所有权条件。ShapeKey、旧记录或未知外部引用相关资源可能保守保留。普通外部 driver 目标的作者值不被本次恢复覆盖，不承诺任意隐藏 Python 引用图或第三方回调竞态的完整证明。

文件提交和补偿不构成跨进程、断电或整个模拟批次的原子事务。预设文件写入成功而随后绑定赋值异常时，只保证恢复原绑定，不承诺撤销已写目标文件。

未操作用户原场景或自然 GUI；没有新增真实 FEM、其他平台或原生性能证据。此前明确暂缓的硬关节、原 Undo 崩溃、权重代理仍未在此版本关闭。性能优化和关机安排继续取消。1.0.25 默认平面精度案例的既有边界保留。
