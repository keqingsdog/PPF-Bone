# 1.0.24：链间弹簧列表与碰撞排除

- 列表中移除重复阻尼文字，右侧用可逐条操作的布尔状态显示该链接的作者碰撞排除。
- 增加骨骼名搜索；一个或多个已选骨骼关联的链接优先显示，原数据顺序和活动项保持。
- 创建时同时启用双斜向与碰撞排除，显示“仅排除直接相邻”；开启后只对直接配对排除碰撞，仍创建斜向链接。该选项默认关闭，只影响新创建的链接，已有链接保留原参数。

独立 Blender 5.1 程序化测试覆盖创建运算符、PLANE/TUBE 各开关组合、排除对生产者、搜索及选中排序、行操作、保存重开。创建进程 PID 53700 与新进程重开 PID 57624 均自然退出 0。锁定状态由测试替身模拟，绘制通过程序化界面探针验证；这些结果不等于真实 GUI 像素验收或后端碰撞排除集合并集实跑。

用户先前暂缓的原 Undo 崩溃和硬球关节仍未作为本次修复；其他平台与场景以实际验证为准。
