# 1.0.22 源码、CI 与文档修订说明

本次修订统一批量工作流和云测试的授权入口：getting-started、两版 run-all-once 与其生成器使用显式输入／仓库变量及手工、默认分支门；blender workflow 的云腿共用不持 OIDC 的授权快照，已获授权且有云腿启动时保持清理路径。保留原任务、后端、例子及清理步骤。相关定向模型与生成检查通过，四个本轮实际工作流通过 actionlint；没有实际触发远端 CI 或验证目标仓库 environment、审批与云角色 trust，强制取消和撤权时资源回收不能保证。

三份源码说明明确历史自动裁剪／代理无重叠验收已被撤回，标明 README 中现有徽章和下载属于上游，并解释源码 ZIP 与发布物的目录边界；不虚构 fork 地址或 Git 历史。原有 CPU、CUDA、Metal、ROCm 源码与构建路线保留，不代表各后端在本轮均已实机运行。

P05 为未确认的 timer 上下文风险：旧 5.1 GUI 自然事件循环已有单骨、模式切换的限定证据；当前 1.0.21 私有安装的补充探针观察到两根骨的 OBJECT 刷新及一根 POSE 刷新，标签和值可读，EDIT 等待期间没有新增刷新。该探针在私有文件加载后同一测试回调中使用失效上下文，随后退出调用发生 Blender 原生崩溃，故本次探针失败，load 后 timer 和插件注销尚未验收。不能将该测试崩溃归因于产品 P05，也不能宣布 P05 全部关闭。

原生 Undo 崩溃与硬球关节按用户决定暂缓；CUSTOM 回滚交 Linux 检查；按权重生成代理仅待办。第三方许可完整审计、干净机器构建和 Linux/macOS 原生求解仍有未验证范围。

早期测试写入用户偏好及系统临时 quit.blend 的影响范围因缺少事前副本未知。原始私有报告、崩溃文件、退出恢复文件及用户偏好不放入公开分享包。新 ZIP 的实际安装结果和最终交付状态以本次回执为准。
