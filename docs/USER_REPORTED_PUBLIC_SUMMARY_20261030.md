# 骨骼代理与播放反馈：公开摘要

此页概述已定位问题和验证边界，不包含原始用户报告或现场数据。原始报告另作私有交接，不能用新建测试场景代替未保存的原现场。

- 骨架和代理的变换读取顺序可能造成偏移；活动变换期间过早修改代理网格也会使取消操作留下变化。修复后，定向测试覆盖了变换确认与取消，仍不能外推全部骨架和约束组合。
- 已针对播放、拖帧和获取动画过程中的具体错误修复并做分段测试。旧现场中自动停止跟随的完整触发过程未精确复现；一个已定位的拖帧崩溃修复不证明任意 Blender 原生崩溃均已根除。
- 后续发现动画求值可能被误识别为作者编辑，以及实时播放中骨骼回传存在额外开销。候选修复、性能测量范围和仍需验证的情况见 [播放驱动与未完成项](BONE_PLAYBACK_AND_OPEN_ISSUES_20261028.md) 和相应版本说明。测试帧率不代表所有工程和设备的表现。
- 原生 Undo 崩溃尚未确认彻底关闭，按当前工作安排暂缓。标准 Undo 不能保证恢复磁盘模拟缓存；插件显式恢复功能应按各自的支持范围使用。

公开说明保留失败和未验证边界；需要原始私有报告的维护者应使用单独交接材料，不应把用户路径或场景信息加入公开源码。
