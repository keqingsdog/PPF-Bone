# 连续扭转与界面：1.0.33 候选

本说明描述开发候选，未代表发布或整体验收。骨骼面板在切换至其他物体时保留显示上下文，代理缩放支持本地、世界轴切换，代理与链间弹簧显示层可分别控制；实际界面验证仍按对应测试范围解释。

连续扭转按已接受的运动累计，跨越 180°不自动回绕，360°仍表示拧过一圈。选中连续关节涉及的刚体采用经校验的准确旋转拟合，拟合会同步读回数据，可能产生性能开销；混合场景中共享该刚体的其他关节使用同一刚体姿态。此模式按实际采样的受限步进和驱动轨迹追踪，不应将无法观测的任意完整转圈从单一姿态推断出来。

旧 V1 检查点须显式升级：从保存姿态建立新的计数依据，保存前已经经历的圈数无法恢复。V2 记录连续状态及 `selected_covariance_polar_svd_v1` 拟合方案；不兼容或损坏的状态应拒绝恢复，不能静默重置。公开升级要求原后端和原组件路径保持一致，包括 receipt 的 exe_path 和 dll_path；只允许已验证的旧版本到当前版本的程序及库内容身份和 source stamp 变化。切换到另一个后端并续算旧缓存并非本轮已实现或验证的公开功能。

最终 CPU 隔离小场景实际完成 15 秒、361 帧和约两圈，另有受驱动回零证据；SVD9 测试覆盖 V1 升级与 V2 跨进程推进，五项 C4 事务测试通过。这些结果范围有限，真实根控制及 FEM 故障场景尚未测试；原失败场景的私有副本已由 CUDA 缓存直接在 CPU 原生求解器上续算至第 52 帧并通过限定检查；它没有经过公开操作入口，不能证明 UI 可跨后端续算。公开 CPU 续算入口已用真实旧版 d454 私有封存工程通过：旧 V1 显式升级、启动失败显示 FAILED 后同一 Blender 直接重试、新进程普通 V2 续算均成功；该流程未恢复旧 status，也未修改封存 receipt、command 或场景。此验证限定为相同 CPU 后端及原组件路径，不代表跨后端或全部故障场景通过。CUDA 小场景实测已完成：运行进程正常退出，输出 0–360 共 361 帧；独立几何解算末帧累计扭转 12.5663378293 弧度，最大相邻帧变化 0.0741035736 弧度；生产检查点解码显示第 360 帧时间 15.0099996645 秒、累计扭转 12.5663368278 弧度，圈数已知。此证据仅限此前小场景；本轮验收范围已限定为 CPU，CUDA 暂缓。最终 CUDA 的多圈与 C4 设备测试未完成；ABI 定向测试曾出现内核编号不一致，源码中的排序修正尚未完成 CUDA 设备复验。CUDA 冷续算和原用户场景也未通过本轮验证。Metal 和 ROCm 保留源码和构建路径，本轮未实测。测试日志和用户私有场景不属于源码发布材料。

请先按 [构建说明](../BUILDING_BONES.md) 分别构建所选后端及匹配的服务和 Python 绑定。功能验收需在自己的隔离工程中实际运行：验证已知旋转及跨缝、连续一圈和两圈、停止保存后新进程续算、旧缓存显式升级及不兼容缓存拒绝；检查结果姿态和恢复力，而非仅检查按钮或编译。CUDA 还需在实际设备运行，并保留正式架构与单精度守卫。源树自带测试可按对应 crate 的 Cargo 测试入口执行；私有原始失败输入不随源码提供。模拟和恢复的通过范围以实际执行结果为准。

## 源码入口与维护边界

- [连续相位与路径证明](../crates/ppf-cts-solver/src/continuous_twist.rs)：accepted 和 trial 分离，使用 full-joint 索引；相对协方差路径界在满足有限性、可逆性和误差条件时参与更紧的界估计，旧保守界仍可回退，不能移除有效性、短弧和净角保护。相对界的结论以最终对应构建和运行证据为准。
- [关节与拟合](../crates/ppf-cts-solver/src/driver/joints.rs)、[步进与事务](../crates/ppf-cts-solver/src/driver/step.rs)：准确拟合仅用于可信选中刚体；试算失败须回滚，C5 提交前预检，成功后才提交 accepted 状态。共享刚体的其他关节读取同一姿态。
- [历史格式与验证](../crates/ppf-cts-solver/src/checkpoint_history.rs)、[恢复调度](../crates/ppf-cts-solver/src/backend.rs)、[模型升级](../crates/ppf-cts-solver/src/twist_overlay.rs) 与 [CLI](../crates/ppf-cts-solver/src/main.rs) 处理 V1/V2、准确拟合方案和恢复顺序；积分旋转不可擅自重置。
- [前端恢复合同](../frontend/_bone_resume_.py)、[插件续算范围](../blender_addon/core/resume_horizon.py) 和 [续算界面](../blender_addon/ui/solver.py) 实现公开入口，必须结合实际选中后端的能力与封存输入校验。

连续角并非无限精度：作者输入的连续扭转范围严格小于 512 弧度，实际累计值投影到 f32 时还检查有限性、幅度及最大 0.0001 弧度投影误差；超出安全条件应拒绝而非静默回绕。可从源码 crate 运行 Cargo 定向测试，例如 `cargo test --release -p ppf-cts-solver --features cpu continuous_codec_tests`，并按构建说明选定对应工具链和后端。本轮 CPU 多圈与上述公开续算流程已在隔离工程通过；用户原失败场景的 CPU 原生续算至第 52 帧属于独立证据，未证明公开入口可跨后端续算。真实根/FEM 故障及 CUDA、Metal、ROCm 仍须对应环境验证；私有场景数据不随源码提供。
