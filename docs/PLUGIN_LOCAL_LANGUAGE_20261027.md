# 插件独立语言与Windows兼容验证（2026-10-27）

用户已否定此前“同步Blender”方案。本次插件语言仅作用于插件自有文案，不再修改Blender全局语言或界面、提示、数据名称翻译开关。

## 使用

在插件偏好设置选择跟随Blender、中文或English。保存选择后正常重启Blender，界面和原生属性说明统一按新选择生效；切换不会在运行中注销或重建作者属性。跟随模式在启动时读取Blender实际界面语言。

选择仅保存到Blender用户CONFIG目录下的`ppf_contact_solver/language.json`，内容为schema与choice，不是工程数据。默认AUTO且未使用时不创建配置目录。旧版已保存的非AUTO选择会在正常注册后迁移为待生效选择；坏配置回退AUTO，写失败会恢复偏好选择并显示错误。

插件自有属性名称、静态枚举、说明、操作标签及提示使用同一启动语言。Blender自带快捷键、通用右键菜单和其他原生控件附加文字仍属于Blender。说明前的`PPF:`用于避免Blender再次翻译插件已选的文字。用户对象、骨骼、组、路径和预设名称保留原文。

英文模式仍有部分既有中文词条及格式化文案，没有宣称完成全部英文翻译。中文普通文案使用中文，专业缩写保留。

## 实现范围

本地属性工厂只处理插件自有属性的显示元数据，保留identifier、静态枚举编号／顺序／默认值与原有回调。局部布局与类准备接口仅作用于插件自己的绘制和注册，不改写全局bpy翻译函数、属性工厂或默认翻译上下文。

多选参数的原生工厂身份判断及动态枚举提示字符串生命周期已做针对修复；真实多骨枚举／向量分量事务、原生RNA说明和操作元数据有直接回归。语言选择前后及保存重开后的作者值和恢复曲线集合保持。

本次没有修改、删减或重新编译求解器／前端。继续使用现有配套CPU／CUDA运行包；官方其他后端源码和构建路线保留。

后续所有相关测试在任何插件或偏好操作前，检查私有目录已存在且Blender实际CONFIG路径等于该目录；修正后的旧偏好迁移已在真正隔离配置中通过。事故备份和个人偏好文件不放入分享源码／插件包。

集中审查的发布结论限定于插件独立语言、六版各已通过子集及五个完整窗口节点；没有删除5.0功能或宣称其窗口完整通过。正常重启Blender后载入新版。
