原低层拒删或删除失败时会返回False，但单Pin和批量上层仍清“已捕获”标记、删除EMBEDDED_MOVE并报告成功。现False沿调用链保留文件、内存、归属、捕获标记和sentinel；批量准确报告成功与保留数，全失败取消。存在失败时不再执行末尾扫除，避免同批次第二次删除把文件删掉而标记仍保留。

原跟随在所有Transform期间暂停，姿态模式预览也被跳过。现Pose作者态用冻结的局部偏移做矩阵预览，变换中不烘网格、不改基线；确认／取消后结算，不从浮点分解后的矩阵反复学习偏移。

用户新`Untitled.crash.txt`的原生栈位于pyrna创建／属性读取，Python位于删除代理清理读取网格处。Undo/Redo现在使旧清理回调失效，post仅延迟重新查找新对象；不持旧RNA引用穿过身份重建，空数据保守跳过，同时保留普通删除后的清理。

## 恢复力零点

默认零点取传输／构建时**模拟起始帧的姿态模式相对角度**。参数编码先求值到模拟起始帧，构建据这些初始世界帧生成关节参考相对旋转；不直接把编辑模式静置姿态当零点。任意拖到一帧再点Run不会重新定义已构建的参考；改起始姿态后需重新传输、构建。显式驱动目标另按驱动设置处理。
