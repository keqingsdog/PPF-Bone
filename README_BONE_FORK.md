## 源码和运行产物

源码根目录直接包含 `Cargo.toml`、`LICENSE`、`crates/`、`frontend/`、`blender_addon/` 和 `.github/`。本快照不含 Git 历史；上游来源见 [NOTICE_BONE_FORK.md](NOTICE_BONE_FORK.md)。

本仓库应包含所有自有 Rust、C++、neutral kernel、代码生成器和构建配方。编译产生的目标文件、后端库、求解器、Python 环境、CUDA 工具包、模拟缓存和本机产品配置不属于源码发布输入。

Windows 与 Linux 使用相同的骨骼/关节源码和 kernel 表，平台差异由工具链、动态库名称、加载路径和构建脚本处理。保留上游CPU、CUDA、Metal、ROCm源码与构建路线。当前Windows CPU普通场景已用修改后的前端实际Build→Run通过；CUDA已有骨链限定运行证据。Linux及其他硬件需要接手方实际编译和运行。CPU已有1.0.25限定骨骼烘焙与重新传输证据，尚未证明所有CPU骨骼场景；Metal、ROCm本轮仍未实跑。

普通场景保持官方后端路径，不要求绑定骨骼发布产品。真实扩展使用选中产物的必要ABI与功能探针；历史ABS04兼容只在显式选择该产品时启用。完整运行包使用相对根目录配置，不能依赖原开发机盘符、旧`.obj`/`.lib`或旧Cargo `OUT_DIR`。失败时应修复输入或接口，不能删除校验。

源码运行配置与历史固定产品的区别见[源码配置说明](docs/SOURCE_PROFILE_BOUNDARIES_20261030.md)。

## 砂粒续算与接触时基

含滚动砂粒的新 State 断点携带已接受的角速度历史，需要支持该格式的新求解器读取。旧断点没有保存这段历史，只能以零角速度种子冷恢复，无法还原缺失历史，也不能称为精确续算。请保留原断点并确认所用求解器支持对应格式。

动态网格、静态网格和解析几何这三类接触的摩擦装配使用当前实际积分试算步长；试算重试时应以该次实际步长为准。上述修改的实际恢复和接触行为仍需按目标后端及场景验收，不由这段说明推断测试通过。

## 链间弹簧的搜索和批量编辑

搜索过滤后，刚度、颜色和删除等批量操作只处理可见的勾选连接。勾选连接全部被搜索隐藏时，详情保留显示，修改和删除禁用。删除或重排后按连接 UUID 保留活动连接。活动连接被删时清除活动行，用户可重新选择。

## PCG 等待优化

PCG 使用 FP32。旧 Blender 工程和场景配置中保存的实验性 FP16 精度设置在新传输时忽略。旧 FP16 原生输入及其检查点必须从 FP32 重新传输并从头运行，求解器会在输出前拒绝它们。

CUDA 在符合条件的无投影、根和锁的混合刚柔 Newton 求解中默认合并 GPU 回读。设置 `PPF_PCG_COALESCE_MIXED=0` 可在诊断时关闭这一优化。`PPF_PCG_TIMING_RECEIPT=1` 输出实际分支、同步次数、耗时和迭代数。其他后端保持原有默认路径。

## R10 本地修复

Fetch 用求解时绑定的表面映射回读结果。同尺寸错序、缺失映射或映射已被参数重建替换时，回读保留已有缓存并报告失败。从其他场景发起的回读会检查目标当前的场景归属。时间线使用结果自己的缓存起点。已有有效运行记录和原始数据身份的旧直接映射结果仍可手动读取。

无变化更新参数保留当前上传和运行状态。帧间保存退出等到下一个可保存帧。第 0 帧断点保留原文件，最新断点入口会明确提示不支持第 0 帧续算。求解器在写入或清理输出前获取排他锁。

速度事件写入历史位置时使用上一已接受的积分时长。单位时间缩放的普通场景若在 Newton 和 CCD 路径缩步，会回滚当前试算、重新采样运动输入和事件，再进行求解与碰撞检查。已安装的 root/FEM 控制、其他专用宿主重试组合和非单位时间缩放保持原路径。

Windows CPU 定向实测覆盖表面映射、跨场景、无变化更新后的真实续算、输出锁、帧间保存、变步长速度和普通场景的运动时序。其余平台和混合控制的物理结果须分开验证。
